# PK Navigator — instrukcja

1. Otwórz aplikację i wybierz miejsce startowe.
2. Jeśli wybierasz numer sali, stań przed drzwiami, twarzą do sali.
3. Wyszukaj cel w A, B lub C i wybierz „Prowadź tutaj”.
4. Wykonaj wskazany obrót lub skręt, a następnie przejdź po grubej niebieskiej linii do złotego punktu.
5. Potwierdź dotarcie przyciskiem. Każdy zakręt i każde przejście między budynkami ma osobną instrukcję.
6. Przy schodach lub windzie potwierdź osiągnięcie wskazanego poziomu. Aplikacja pokaże właściwy plan.

„Cała instrukcja” pokazuje wszystkie kroki. „Głos” odczytuje bieżące polecenie, jeśli przeglądarka obsługuje polską syntezę mowy. „Pokaż punkty” włącza sieć punktów i połączeń. Mapę można przesuwać i powiększać; grubość linii trasy nie maleje przy oddalaniu.

Prototyp obejmuje wyłącznie 18 nowych planów A, B i C. B jest łącznikiem na poziomach −1, 0 i 1. Start i kolejne kroki potwierdzasz ręcznie.

Nie ma tras do B 06-1, C 011-1, C 206, C 405 i C 504 — rysunki nie pokazują potwierdzonego wejścia. Przy biurze C 202 widnieje uwaga o powtórzonym numerze 201 na planie. Nie podajemy odległości w metrach, ponieważ plany nie zawierają skalibrowanej skali.

Uruchomienie paczki: w jej folderze wykonaj `npm start` (wymagany Node.js) i otwórz http://127.0.0.1:4173/.
